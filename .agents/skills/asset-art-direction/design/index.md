# Visual standard index

Read this to locate a visual criterion, not to load all rules. Guidance baseline:
**2026-10-13**, overgrown, muted and gloomy painted woodland miniature style
led by the [W0 Whisperwood board](../references/index.md#whisperwood). The qualitative
starting direction is adopted; examples are inspected existing pictures, not a
new artist-accepted asset pass. Numeric calibration and actual game view sizes
are not established. This document does not change executable defaults.

| Canonical rule owner | Concern |
|---|---|
| [D01](silhouette.md#d01) | Silhouette, proportions and role hierarchy |
| [D02](shape-edges.md#d02) | Selective softened edges and preserved broad planes |
| [D03](palette.md#d03) | Palette/value/saturation relationships |
| [D04](surfaces.md#d04) | Painted material hierarchy, geometry versus fine marks |
| [D05](contacts.md#d05) | Planted contacts, clustered detail and rest areas |
| [D06](emission.md#d06) | Form-preserving magic and coherent water |
| [D07](consistency.md#d07) | Family inheritance and thematic exceptions |
| [D08](presentation.md#d08) | Comparable presentation and actual-size readability |
| [D09](evidence-cost.md#d09) | Evidence, resource restraint and regressions |

Each owner separates observed image convention, chosen adaptation, rationale,
scope, qualitative pass/fail and uncertainty. “Fail” examples describe review
criteria, not measured failures certified on current assets. See the
[reference IDs](../references/index.md) and [crop anchors](../references/evidence.md).

Family overrides name the rule they qualify; they never copy thresholds. Recipes
link their primary rule and existing code owner. Shared implementation facts live
in the [pipeline index](../pipeline/index.md), with tunables owned by code.
If a visual metric becomes executable, its numeric owner moves to existing
settings/checks; retain only rationale/examples and a symbol link here.

Revising the standard: record date, changed rule, evidence, reason and scope here;
keep originals intact and preserve accepted baselines. A guidance change does not
silently migrate saved sources or increment paint/style versions. New creative
motifs, numeric targets or production quality work need separately scoped approval.
