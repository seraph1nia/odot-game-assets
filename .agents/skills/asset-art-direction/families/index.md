# Family routes

Choose one family, then one procedure; common visual criteria stay in the
[design owners](../design/index.md), not copied into each family.

| Selected catalog family | Read |
|---|---|
| Village/economy/defense/civic building | [Buildings](buildings.md) |
| Hero/evil unit and equipped/removable weapon | [Units/equipment](units.md) |
| Forest tile/component or dreaming adaptation | [Environment](environment.md) |
| Standalone village prop, weapon or terrain base | [Props/terrain](props.md) |

Resolve ID/source/selector/reference using [reference metadata](../references/index.md).
An environment component's tile picture is contextual evidence, not a supplied
turnaround. Empty UI/effects/audio folders are not invented reference families.
