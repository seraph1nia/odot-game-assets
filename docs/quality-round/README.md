# Reference-led asset quality iteration

The bounded iteration assesses all **105 canonical IDs**, delivers changes to
**27 GLBs** (23 authored/library-dependent IDs plus four additional palette-fidelity
corrections), and explicitly retains **78 unchanged IDs**. Coverage is not a promise
that all 105 are newly improved, reference-perfect or final under a game camera.

## Review entry points

- [Coverage ledger](coverage.md): every canonical source/selector/reference/crop and
  concrete refinement, retained baseline or limitation.
- [Buildings](first-batch.md) and [forest/units](forest-units.md): actual hypotheses,
  iteration-1 rejection/iteration-2 decisions and 18 matched source-image pairs.
- [Portable acceptance](portable-review.md): 27 current before/original pairs,
  emission/body-state comparisons, all-eight-unit actual 1× six-clip observations,
  complete-viewer crops and software/halo/starter-motion limits.
- [Export fidelity](export-fidelity.md): real before-fail/after-pass fixture, earliest
  evaluated DATA-versus-effective OBJECT material loss, rejected modifier-off
  alternative and exact six-ID correction closure.
- [Resources](resources.json): unique primitive triangles/material/image definitions
  and physical bytes, not instances, GPU memory, draw calls or FPS.

## Mechanical evidence

Existing selected export/round-trip/rig/bounds/material/style/packed-channel checks
pass. Source-style inventory, forest footprint/endpoints/library freshness and
attachment checks from the earlier authorized campaign remain valid; no all-105
rebuild/export/render repetition was used after the exporter fix. Seven new real
selected-export material fixtures and 17 existing style fixtures pass (24 total).
Fast route passes 47 tests and two inline JavaScript programs. [Logs](checks/) retain
actual failure-before, success-after and worker outputs.

## Scope and limitations

No source materials/UVs/rigs were overwritten to conceal the serialization defect.
Manual compositions/maps remain; shared prototypes were edited once with exact
embedded-dependent propagation. Dreaming content remains authored adaptation, not
invented reference matching. Source Fog Glow is not a GLB effect; existing viewer
emission-on/off is not bloom-on/off. SwiftShader cadence is not native GPU evidence.
Provisional 480/192/96 boxes are not measured game occupancy; generic crossbow aim,
rigid cloth, incidental cap edits, remaining fauna/composition opportunities and
lack of full component turnarounds are disclosed, not validator-certified.

The same no-mistakes pipeline owns final review/fixes/tests/docs/lint/push/PR/CI.
No manual publisher, independent reviewer, game consumer change, merge or release
follows from this implementation-worker review.
